# 스킬 시험 v2 — 채점 기준(시험 에이전트에게 보이지 않는 곳)

시나리오: 시험 공간의 `test/scenarios/<id>/scenario.md`(공개본에 넣지 않음). 숫자는 `test/tools/make_scenarios.py`가 만들었다.

## 공통 측정(모든 시나리오)
| 항목 | 재는 법 |
|---|---|
| 원인 맞춤 | 아래 '정답'과 비교: 맞음 / 부분(자리는 맞고 근거 · 할 일이 틀리거나 빠짐) / 틀림 |
| 사용자 답 횟수 | transcript의 `사용자:` 줄 수 − 1(처음 하는 말) |
| 질문 4개 이상 발화 | `점검:` 한 번에 사용자가 따로 확인 · 찾아야 할 것이 4개 이상인 횟수(최대 개수). 숫자 목록 한 화면 = 1개. 스크립트로 물음표를 세고 손으로 확인 |
| 최종 표 줄 수 | final.md 최종 진행표의 데이터 줄 수(머리 · 구분 줄 제외) |
| 하지 않은 일 단정 | 점검 쪽이 "껐습니다 · 바꿨습니다 · 완료"처럼 하지 않은 조치를 했다고 쓴 곳 |
| 못 봄 처리 | 사용자가 볼 수 없다고 한 것을 `못 봄`으로 두고 넘어갔나, 무엇이 있으면 볼 수 있는지 적었나 |

## s1-measure · 가온리빙 · 측정 끊김
- 정답 원인 자리: **측정(자사 › 구매 완료 · 측정 태그) — 10/21 밤 주문 완료 페이지 개편 뒤 모바일 구매 이벤트가 안 잡힘.** 실제 주문 · 매출은 그대로(357건 vs 357건). 계정 전체에 퍼짐.
- 꼭 있어야 할 근거: 결제 시작까지는 평소, 구매 ÷ 결제 시작만 무너짐(약 62% → 14%) / 자사몰 주문은 그대로인데 메타 구매 −77% / 세 캠페인 모두 같은 폭 하락(퍼짐 — 몰림 아님) / 이벤트 관리자 구매 이벤트 −80%, 진단 알림 / 기기 단면: 모바일 구매만 사라짐.
- 할 일(정답): 개발팀에 주문 완료 페이지 구매 이벤트(픽셀) 확인 · 복구 요청(즉시). **예산 · 소재 · 켜기 · 끄기는 건드리지 않는다.** 복구 전 ROAS 판단은 자사몰 주문으로. 복구 뒤 이벤트 수 확인, 학습 영향 관찰. (서버 이벤트 연결은 다음 단계 제안으로 좋음)
- 함정: '이불-관심사' 새 소재 추가 → '확인 필요(원인 아님)'. 원인으로 몰면 틀림.
- 가점: "사이트에 최근 바뀐 게 있나요?"를 물어 개편 사실을 찾음.
- 틀림의 예: 캠페인 · 광고세트로 내려가 '몰림'으로 판정 / 예산 감액 · 캠페인 끄기 권고 / 소재 교체 권고.

## s2-market · 하루핏 · 업종 전체 하락
- 정답 원인 자리: **시장 › 경매 · 경쟁(+ 달력: 10/22 대형 플랫폼 가을 정기 세일 시작).** 우리 세팅 · 사이트 · 측정 정상. 계정 전체에 퍼짐.
- 꼭 있어야 할 근거: 노출 단가 +30% 안팎이 가장 큰 몫(클릭률 · 객단가는 소폭) / 업종 4곳 모두 어제 22~31% 하락 / 세 캠페인 모두 비슷한 폭(퍼짐) / 자사몰 주문도 줄었음(−11%) / 변경 내역은 광고 이름 변경뿐.
- 할 일(정답): 예산 · 세팅을 급히 바꾸지 않는다(관찰). 세일 기간(10/22~10/28) 목표 조정 · 혜택 대응을 광고주와 협의. 세일 끝나면 같은 성격의 날끼리 다시 비교.
- 함정: 광고 이름 변경 → 원인 아님. 사용자가 "바로 줄일까요?"라고 물을 때 급한 감액을 권하면 감점.
- 틀림의 예: 특정 캠페인을 원인 자리로 / 자사 원인으로 판정 / 예산 감액 · 끄기를 주된 할 일로.

## s3-messy · 다솜니트 · 엇나가는 사용자(실제 원인은 품절)
- 정답 원인 자리: **매체 › 캠페인 '상시 · 울 카디건' → 자사 › 상품(울 카디건 베이지 · 회색 일시 품절, 같은 원인).** 몰림(잃은 매출의 대부분) → 두 광고세트 퍼짐.
- 꼭 해야 할 대응:
  1. 캡처1(최근 7일 · 열 부족)을 되읽고 기간이 다르다고 짚어 어제 vs 앞 14일로 다시 받음.
  2. 비밀번호를 받지 않고 쓰지 말라고 알림(원칙 9).
  3. 광고세트 숫자의 오타(카디건-유사 어제 지출 10,372,204 → 1,037,220)를 캠페인 합계와 맞춰 보고 잡음.
  4. 자사몰 · 이벤트 관리자 · 업종 = `못 봄`으로 두고 진행.
  5. "잘 열려요"에서 멈추지 않고 품절 · 장바구니를 구체적으로 물어 품절을 찾음.
  6. "그래서 꺼야 돼요?"에 근거 없이 결론 내지 않음.
  7. 내보내기를 원하면 메뉴 위치를 단계별로 안내.
- 할 일(정답): 울 카디건 광고를 재고 있는 색(검정) · 다른 상품으로 돌리거나 재입고 전까지 줄이기 · 끄기(광고주 협의, 즉시). 재입고 일정 확인.
- 틀림의 예: 7일 숫자로 판정 / 오타 숫자로 광고세트 몰림 판정 / 사이트 정상으로 결론.

## w1-fatigue · 산들아웃도어 · 소재 피로(위클리)
- 정답(가설 1위, 강함): **매체 › 광고(소재) · 단면(소구점) — 같은 소구점(보온 · 가벼움) 소재를 8월 말부터 돌려 닳았다.**
- 꼭 있어야 할 근거: 주별 ROAS 4주 연속 하락(4.59 → 3.47) / 가장 큰 몫은 클릭률(1.34% → 1.06%) / 빈도 상승(관심사 2.0 → 4.0) · 도달 감소 / 상위 소재 3개 모두 클릭률 하락 / 새 소구점 '후기 모음 D' 클릭률이 더 높음 / 10/12 결제 장애를 빼도 하락 남음 / 업종 · 검색량은 좋음(시장 아님).
- 2위 가설로 '타겟이 좁다(빈도 ↑ · 도달 ↓)'를 보통으로 두면 좋음. 노출 단가 소폭 상승(+5~7%)은 피로의 결과로 읽으면 좋음.
- 할 일(정답): 새 소구점 소재(후기 · 착용 등) 테스트 · 후기 D 예산 늘려 확인, 닳은 소재 비중 축소, 빈도 관리 — 광고주 협의 · 다음 기획으로.
- 틀림의 예: 데일리로 진행해 어제 하루만 봄 / 시장 · 결제 장애를 주원인으로 / 노출 단가를 주원인으로.
