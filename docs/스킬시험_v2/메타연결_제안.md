# 제안 — 메타 공식 광고 연결 서버(MCP) 갈래

조사만 했다. 실제 계정 연결 · 접근은 하지 않았다.
확인한 곳은 메타 개발자 문서(개요 · 시작하기, 2026-10-23 조회)와 참고 스킬 `mikefutia/meta-ads-auditor`이다. 참고 스킬은 이 서버로 주간 점검을 읽기 전용으로 돈다.

## 확인한 사실
- 서버: `https://mcp.facebook.com/ads`. 메타가 직접 운영하고, MCP를 쓰는 에이전트면 붙일 수 있다.
- 할 수 있는 일(문서의 7가지 묶음)
  - 성과 보고서 · 인사이트 읽기
  - 캠페인 · 광고세트 · 광고 만들기 · 고치기(쓰기)
  - 카탈로그
  - 신호 · 데이터 세트 상태(측정 점검에 해당)
  - 도움말 검색
  - A/B 시험 · 전환 상승 연구
  - **활동 기록(변경 내역)**
- 연결 방법
  - 메타 개발자 앱을 만들어 'Create & manage ads with ads MCP server' 사용 사례를 추가한다.
  - Facebook Login for Business 리디렉트 주소를 설정한 뒤 OAuth로 로그인한다.
  - Claude Code는 `claude mcp add --transport http --client-id <앱 ID> meta-ads https://mcp.facebook.com/ads`로, ChatGPT는 개발자 모드의 OAuth로 붙인다.
  - **Claude 웹 · 데스크톱 연결 방법은 문서에 없다**(사용자 지정 커넥터로 될 가능성은 있으나 확인 안 됨).
- 권한: 최소 `ads_mcp_management` + `ads_read`(또는 `ads_management`). 문서에는 읽기 전용 모드가 따로 적혀 있지 않다. 그래서 **`ads_read`만 주는 것이 사실상 읽기 전용**이다.

## 우리 스킬에 주는 뜻
지금 사용자에게 화면을 열어 보내 달라고 하는 것 중 아래는 연결로 직접 읽을 수 있다.
| 카드 | 지금(안내) | 연결되면 |
|---|---|---|
| 1 · 2 | 계정 · 캠페인 · 광고세트 숫자, 일별 파일 | 인사이트로 어제 · 앞 14일 · 일별을 직접 읽음(파일 · 캡처 오류가 없어짐) |
| 4 | 기록(변경 내역) · 켜짐 · 반려 · 학습 · 결제 | 활동 기록 · 개체 상태를 직접 읽음 |
| 5 | 이벤트 관리자 구매 이벤트 수 · 진단 | 신호 · 데이터 세트 상태로 읽을 수 있을 가능성(도구 이름 미확인) |
| W1 · W2 | 주별 · 광고 단위 파일 | 직접 읽음 |
| 3 · 자사몰 · 업종 | 휴대폰으로 열기 · 자사몰 관리자 · 동료 소식 | **그대로 사람에게 묻는다**(메타 밖의 일) |

## 제안
1. **지금 SKILL.md에는 넣지 않는다.** 이유는 셋이다.
   - 연결해 시험한 적이 없다.
   - Claude 웹 연결 경로가 문서로 확인되지 않았다.
   - 서버에 쓰기 도구가 있어 권한을 잘못 주면 '하지 않은 일을 하지 않는다'는 전제가 무너질 수 있다.
2. 사용자가 시험 계정을 `ads_read`만으로 연결해 볼 수 있으면, 아래 갈래를 SKILL.md '진행 원칙' 뒤에 넣는다. 그다음 같은 시나리오 4개를 '연결 있음'으로 한 번 더 시험한다(숫자 직접 읽기 · 질문 횟수 감소 · 쓰기 도구를 부르지 않는지).
3. 넣을 문안(초안)
   ```
   ## 메타 광고 연결이 있을 때
   - 이 대화에 메타 광고 연결(mcp.facebook.com/ads)이 있으면, 카드 1 · 2 · 4 · W1 · W2의 숫자와 변경 내역은 사용자에게 묻지 않고 직접 읽는다. 읽은 기간과 숫자를 짧게 보여 주고 시작한다.
   - 사이트(카드 3), 자사몰 주문, 업종 소식, 행사 일정은 연결로 알 수 없으니 지금처럼 묻는다.
   - 읽기만 한다. 광고를 만들거나 고치거나 끄는 도구는 부르지 않는다. 사용자가 원하면 '광고 관리자에서 이렇게 바꾸세요'로 안내한다.
   - 연결이 없거나 권한이 없으면 지금 카드대로 화면을 안내한다.
   ```
4. 대시보드 · 엔진 쪽: `engine/collect_meta.py`가 하는 수집을 이 서버로 대신할 수 있는지는 엔진 소유 범위라 여기서 판단하지 않는다(조정자 · 사용자 결정).
