# 주소표 — 누구에게나 같은 주소 · 쇼핑몰 종류별 관리자 주소

확인한 날 2026-10-30. **공개 도움말 · 공개 문서로 확인한 것만** 주소로 적었다. 로그인이 필요한 화면의 주소 꼴(계정 번호 · 데이터 세트 번호를 넣는 꼴 등)은 공개 문서에 없어서 `[실계정 확인 필요]`로 두고 메뉴 길만 적었다 — 짐작해 만든 주소로 열지 않는다. 메타 주소는 바뀔 수 있으니 열어 보고 다르면 메뉴로 찾는다(`screen-guide.md`).
- 터미널: 확인된 주소는 바로 열고, `[실계정 확인 필요]`는 들어가는 주소로 연 뒤 메뉴로 간다. 실제 계정에서 열린 주소 꼴을 봤으면 진행표가 아니라 마무리 '못 봄 · 있으면' 밑에 "주소표에 더할 것: …" 한 줄로 알린다(이 표는 사람이 고친다).
- 웹: 확인된 주소는 눌러 여는 링크로 준다(`[광고 라이브러리](https://www.facebook.com/ads/library)`). `<…>` 자리는 채워서 준다.

## 쇼핑몰 종류별 관리자
종류를 알면 관리자 주소를 묻지 않는다. '일별 매출 · 주문' 메뉴로 그날 매출 · 주문 수와 앞 14일을 본다(주문 상세 · 고객 목록은 열지 않는다).

| 종류 | 관리자 주소 | 상태 | 일별 매출 · 주문 메뉴 | 근거 |
|---|---|---|---|---|
| 카페24 | 로그인 `https://eclogin.cafe24.com/Shop` → `https://<몰 아이디>.cafe24.com/admin`(몰 아이디가 주소에 들어감) | 확인함 | 통계 › 매출 분석 › 일별매출(1시간마다 갱신) · 주문관리 › 영업관리 › 전체주문조회 | 카페24 공지(2019-12-10) "로그인 후 https://쇼핑몰아이디.cafe24.com/admin" · 카페24 서비스 안내 '일별매출' |
| 아임웹 | `<사이트 주소>/admin` | 확인함 | 관리자 페이지 › 통계 › 매출(기간별, 4시간마다 갱신) · 쇼핑 › 주문관리 | 아임웹 FAQ(검색 색인 문구 — 본문은 열리지 않음) |
