# roas-check 스킬 — 설치 안내

이 문서의 경로(`docs/` · `dashboard/` · `html/` · `tools/` · `engine/`)는 저장소 맨 위 폴더 기준이다.

메타 광고 ROAS가 떨어졌을 때, 마케터에게 "어디를 열어 무엇을 보내 달라"는 안내를 단계별로 주며 점검을 끝까지 함께 진행하는 스킬이다.
웹 대화에서 도구 없이 쓰도록 만들었다(마무리의 대시보드 링크만 코드 실행을 쓴다). 터미널에서는 브라우저 조작 도구가 있으면 로그인을 부탁하고 화면을 직접 읽는다(아래 '터미널에서 쓰기'). 폴더 구성: `SKILL.md`(단계 카드) · `references/checklist.md`(점검 87개) · `references/screen-guide.md`(화면 위치) · `references/terminal-mode.md`(터미널 판 — 로그인 받고 직접 읽기 · 광고주 설정 파일) · `references/addresses.md`(바로 여는 주소표 — 확인된 것만) · `references/result-block.md`(대시보드에 붙여 넣을 결과 블록) · `scripts/make_link.py`(대시보드 링크 만들기).

| 어디서 | 설치 |
|---|---|
| Claude 웹 · 앱 | 왼쪽 사이드바 **사용자 지정 › Skills › 추가(＋) › Skill 업로드**에서 `roas-check.zip`을 고르고 '업로드'를 누른다. 올린 뒤 켜짐이 기본이다 |
| ChatGPT | 데스크톱 앱은 같은 형식의 스킬을 쓴다. 웹은 플러그인으로 배포해야 할 수 있어 설치 전에 확인한다 |
| Claude Code · Codex | `roas-check/`를 `~/.claude/skills/` · `~/.agents/skills/`에 두면 같은 안내로 동작한다(아래 '터미널에서 쓰기') |

## 써 보기
- "A사 메타 ROAS가 어제 갑자기 떨어졌어" → 데일리 안내(카드 0~6)
- "몇 주째 ROAS가 내려가" → 위클리 안내(카드 W1~W3)
- "예시로 보여 줘" → 지어낸 A사 사례로 시연
- "ROAS 점검 — A사 어제 이어서" → 지난 점검 이어 보기(웹은 마무리에 받은 '다음 점검 첫 말'을 붙이고, 터미널은 작업 폴더의 `roas-설정-<광고주>.md`를 읽는다)
- 캡처만 올려도 된다(기간 · 비교 · 열을 먼저 확인하고 숫자를 되읽는다). 비밀번호는 받지 않는다.
- Claude 웹에서는 생각 중 상태 줄이 영어로 보일 수 있다(제품 표시라 스킬로 바꿀 수 없다). 답 본문은 한국어다.
- 진행표 밑에 Claude 웹이 붙이는 '스프레드시트 만들기' 단추는 누르지 않아도 된다.

## 대시보드와 이어 쓰기
- 대시보드 웹 주소: <https://ohamma8253.github.io/roas-check-skill/> (최신 붙여넣기 판. 누구나 열 수 있다).
- 점검이 끝나면 웹에서는 답 끝에 **대시보드에서 보기** 링크가 먼저, 그 아래 '링크가 안 열릴 때' 쓸 결과 블록(코드 블록) 하나가 나온다. 링크에는 내부 메모도 담기니 팀 안에서만 쓰고, 광고주에게는 공유 메시지만 보낸다. 스킬 폴더의 `scripts/make_link.py`가 블록 JSON을 압축해 링크 `…/roas-check-skill/#r=1.<crc32>.<압축한 JSON>`을 만든다(손으로 만든 링크는 대시보드가 받지 않는다).
  - **Claude 웹 · 앱**: 링크를 누르면 대시보드가 열리고 이번 점검이 바로 들어간다(붙여넣기 필요 없음). 판에 점검일과 원인 자리가 보이면 들어간 것이다. 링크는 스킬이 스크립트를 돌려 만들므로 설정의 코드 실행이 켜져 있어야 한다. 꺼져 있으면 링크 없이 블록만 나온다.
  - **터미널(Claude Code)**: 답에 블록 · 링크 줄은 나오지 않는다(긴 줄이라 옮기다 깨진다). 마무리에서 스킬이 결과 파일 `roas-결과-<광고주>-<날짜>.json`과 공유 메시지 파일 `공유메시지-<광고주>-<날짜>.txt`를 작업 폴더에 쓰고, "대시보드를 열까요?"에 답하면 `make_link.py <그 파일> --open`으로 기본 브라우저에 대시보드를 연다. 같은 날 결과가 이미 있다고 나오면 '이 칸 바꿔 쓰기 — 고친 판으로'(같은 점검을 고친 판) 또는 '따로 남기기 — 같은 날 둘째 칸'(다른 점검)을 고른다. 판에 점검일과 원인 자리가 보이면 들어간 것이다. 안 보이면 그 파일을 '파일에서 읽기(.json)'로 고른다.
- **링크에는 이번 결과 전부가 담긴다.** `#` 뒤는 서버로 가지 않고 브라우저 안에서만 풀리지만, 링크를 남에게 보내면 받는 사람도 결과를 본다. 링크로 들어온 뒤 주소의 `#r=…`는 지워진다(링크 읽기는 대시보드 v4.7부터).
- 링크가 안 열리거나 인터넷이 없으면 블록을 붙인다. Claude 웹은 블록 칸 오른쪽 위 **복사 단추**를 눌러 대시보드(웹 주소, 또는 내려받은 `dashboard/ROAS_점검_대시보드_v4.9_붙여넣기.html` 빈 판)의 '스킬 결과 붙여넣기'에 그대로 붙인다. 복사되는 것은 울타리(```` ``` ````) 없이 JSON만이어도 된다. 칸 이름은 'roas'로 보인다.
- 피드백 뒤에 블록이 한 번 더 나오면 **마지막 블록**(과 그 아래 링크)을 쓴다(같은 날이라 판이 물으면 '바꿔 쓰기'). 터미널은 앞 파일을 그대로 두고 `…-피드백.json`을 새로 쓴 뒤 "새 블록으로 대시보드를 다시 열까요?"를 묻는다.
- 결과는 그 브라우저에 광고주 · 리듬 · 날짜별로 저장되어 다음 점검의 지난 칸이 된다. 판은 결과를 인터넷으로 보내지 않는다.
- 다른 브라우저로 옮길 때는 '이력 내려받기 · 불러오기'를 쓴다. 블록 형식은 `references/result-block.md`에 있다.

## 터미널에서 쓰기(Claude Code)
- **브라우저 조작 도구가 있으면 스킬이 화면을 직접 읽는다.** 기본 안내는 Claude in Chrome 확장이다 — 확장을 깐 Chrome을 켜 두고 `claude --chrome`으로 시작한다(다른 브라우저 조작 도구도 된다). 첫 답에서 스킬이 "메타 광고 관리자에 로그인해 주세요 · 자사몰 관리자에도 로그인해 주세요(없으면 괜찮습니다)"와 광고 계정 · 자사몰 주소 · 점검할 날을 한 번에 부탁한다. 로그인은 그 창에서 직접 한다(비밀번호 · 2단계 코드는 대화로 보내지 않는다). 이어지는 권한 묻기에는 '이 세션 동안 허용'을 고른다 — 스킬이 창을 띄우기 전에 한 줄로 먼저 알린다.
- 스킬은 **읽기만 한다**: 켜기 · 끄기 · 예산 · 게시 · 복제 · 저장을 누르지 않고 조치는 할 일로만 남긴다. 알려 준 광고 계정 · 사이트 밖으로 가지 않고, 자사몰은 결제 직전까지만 간다. 읽은 화면은 작업 폴더 `화면/`에 캡처로 남고 진행표 근거에 '직접 봄'으로 적힌다. 사람에게는 재입고 일정 · 최근 한 작업 · 업종 소식처럼 화면에 없는 것만 묻는다. 자세한 흐름은 `references/terminal-mode.md`.
- 처음 점검 끝에 스킬이 광고주 설정 파일 `roas-설정-<광고주>.md`(광고 계정 · 쇼핑몰 · 못 보는 화면 · 마지막 결과 파일 등 '항목: 값' 줄, 비밀번호 칸 없음)를 보여 주고 남길지 묻는다. 남기면 다음 점검은 "그대로 볼까요?" 한 줄 확인으로 시작하고 어제의 관찰 할 일을 잇는다. 손으로 고쳐도 되고 미리 채워 와도 된다.
- 도구가 없거나 로그인을 원하지 않으면 아래처럼 캡처 · 파일로 진행한다.
- 점검할 캡처 · 내보내기 파일을 한 작업 폴더에 모으고 그 폴더에서 시작한다. 파일은 경로로 알려 준다(예: `자료/캡처1_계정.png`). 스킬은 알려 준 경로만 읽고, 파일을 쓸 일이 있으면 그 작업 폴더에 쓴다.
- **권한 묻기는 종류마다 한 번이다**(2026-10-30 Claude Code v2.1.314 빈 설정에서 잼): 브라우저 스크립트 1회(`ego-browser nodejs < 화면/round-01.mjs` — 2번 "don't ask again") · 파일 쓰기 1회(2번 "for this session") · 대시보드를 여는 `python3 …/scripts/make_link.py … --open` 1회, 그리고 브라우저 도구의 사용 안내 읽기 1회. 첫 창에서 '이 세션 동안 허용'(2번)을 고르면 그 뒤 회차(피드백 뒤 다시 열기 포함)는 묻지 않는다. 브라우저 스크립트의 '다시 묻지 않기'는 작업 폴더 `.claude/settings.local.json`에 `Bash(ego-browser nodejs *)`로 남아, 같은 작업 폴더에서 다음 날 시작하면 묻지 않는다(파일 쓰기는 세션마다 1번). 스킬은 스크립트를 작업 폴더 `화면/round-NN.mjs` 파일로 쓰고 같은 꼴 한 줄로 돌린다 — heredoc으로 넘기면 '이 세션 동안'을 골라도 매번 영어 '난독화(obfuscation)' 경고와 함께 다시 묻는다. 명령 설명은 한국어로 '무엇을 읽나 · 읽기만'이 보인다. 스킬은 명령을 `&&` · `$( )` · 파이프 없이 한 줄로 돌린다. 아래 상태 줄에 보이는 금액은 추정치다(로그인 요금제 안에서 쓴다).
- 브라우저가 열리지 않거나 인터넷이 없으면 파일로 넘긴다. 결과 파일 `roas-결과-<광고주>-<날짜>.json`을 대시보드 '스킬 결과 붙여넣기' 칸의 **파일에서 읽기(.json)**로 고르거나 글 상자에 끌어 놓는다(메모 · 피드백도 함께 붙는다). 파일을 열어 내용을 그대로 붙여도 된다. '이력 불러오기'는 이력 파일(내려받기로 만든 것)용이다.
- 화면에서 `roas-check` 줄 아래 `{`부터 `}`까지 끌어 고른 글도 대시보드가 읽는다. 창을 넓히고 오른쪽 파일 창을 닫은 뒤 고르는 편이 깨끗하다.
- 링크를 직접 만들려면: `python3 roas-check/scripts/make_link.py 결과.json`(링크 한 줄) · `--open`(브라우저로 열기) · `--check <링크>`(되풀어 같은지 보기). 파이썬 3.8 이상, 표준 라이브러리만 쓴다.

## 시험한 사례(2026-10-23, 6모델)
행사 종료 뒤 켜진 캠페인 · 측정 끊김(주문은 그대로인데 메타 구매 급감) · 업종 전체 하락(시장) · 서툰 사용자(캡처만 · 기간 틀림 · 오타 · 품절) · 소재 피로(위클리). 보고: `docs/스킬시험_v2.md`. 그 뒤 실제 Claude 웹 · 터미널에서 써 본 시험(2026-10-26~30)의 요약은 저장소 맨 위 `README.md`의 '어떻게 만들고 시험했나'와 `CHANGELOG.md`에 있다.

## 고칠 때
점검 항목의 정본은 점검 지도(`html/checks.js`)다. 고친 뒤 `python3 tools/gen_checklist.py`로 `references/checklist.md`와 `engine/checklist.json`을, `python3 html/build.py`로 점검 지도(`dashboard/ROAS_점검_지도.html`)를 다시 만든다.
자동 수집 · 분석 · 대시보드는 스킬이 아니라 `engine/`에 있다(점검 회로 대시보드 생성).
