# roas-check 스킬 — 설치 안내

메타 광고 ROAS가 떨어졌을 때, 마케터에게 "어디를 열어 무엇을 보내 달라"는 안내를 단계별로 주며 점검을 끝까지 함께 진행하는 스킬이다.
웹 대화에서 도구 없이 쓰도록 만들었다. 폴더 구성: `SKILL.md`(단계 카드) · `references/checklist.md`(점검 78개) · `references/screen-guide.md`(화면 위치).

| 어디서 | 설치 |
|---|---|
| Claude 웹 · 앱 | 설정의 기능(Capabilities) › 스킬에서 `roas-check.zip`을 올린다 |
| ChatGPT | 데스크톱 앱은 같은 형식의 스킬을 쓴다. 웹은 플러그인으로 배포해야 할 수 있어 설치 전에 확인한다 |
| Claude Code · Codex | `roas-check/`를 `~/.claude/skills/` · `~/.agents/skills/`에 두면 같은 안내로 동작한다 |

## 써 보기
- "A사 메타 ROAS가 어제 갑자기 떨어졌어" → 데일리 안내(카드 0~6)
- "몇 주째 ROAS가 내려가" → 위클리 안내(카드 W1~W3)
- "예시로 보여 줘" → 지어낸 A사 사례로 시연
- 캡처만 올려도 된다(기간 · 비교 · 열을 먼저 확인하고 숫자를 되읽는다). 비밀번호는 받지 않는다.

## 시험한 사례(2026-10-23, 6모델)
행사 종료 뒤 켜진 캠페인 · 측정 끊김(주문은 그대로인데 메타 구매 급감) · 업종 전체 하락(시장) · 서툰 사용자(캡처만 · 기간 틀림 · 오타 · 품절) · 소재 피로(위클리). 보고: `docs/스킬시험_v2.md`.

## 고칠 때
점검 항목의 정본은 점검 지도(`html/checks.js`)다. 고친 뒤 `python3 tools/gen_checklist.py`로 `references/checklist.md`를 다시 만든다.
자동 수집 · 분석 · 대시보드는 스킬이 아니라 `engine/`에 있다(점검 회로 대시보드 생성).
