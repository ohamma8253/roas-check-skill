# roas-check — 메타 광고 ROAS 저하 점검 스킬

메타(페이스북 · 인스타그램) 광고의 ROAS가 떨어졌을 때 원인을 순서대로 좁혀 가는 **대화형 점검 스킬**과, 점검 결과를 한 장으로 보여 주는 **대시보드**다.

- 스킬은 대화로 진행한다. "어디를 열어 무엇을 보내 달라"를 카드 한 장씩 안내하고, 받은 숫자로 원인 자리를 좁힌다. 웹 대화(Claude 웹 등)에서 도구 없이 쓰도록 만들었다.
- 점검 순서는 바깥에서 안쪽이다. 정말 떨어졌나 → 어느 캠페인 · 광고세트에 몰렸나 → 웹 상태 · 매체 설정 · 측정 · 시장 순으로 본다.
- 대시보드는 판정 엔진이 만든 결과를 점검 이력판, 체크리스트, 할 일, 진행 순서 탭으로 보여 준다.

어베어의 사내 과제(미션)에서 시작했다. **시험에 쓴 광고주 이름과 숫자, 대시보드 예시('A사(예시)')는 모두 지어낸 것**이다. 실제 계정의 데이터는 들어 있지 않다.

## 스킬 설치 · 쓰는 법
**Claude 웹 · 앱**: 설정 › 기능(Capabilities) › 스킬에서 `skill/roas-check.zip`을 올린다.
다른 환경(ChatGPT · Claude Code · Codex)은 `skill/README.md`를 본다.

대화에서 이렇게 시작한다.
- "메타 ROAS가 어제 갑자기 떨어졌어" → 데일리 점검(카드 0~6)
- "몇 주째 ROAS가 내려가" → 위클리 점검(카드 W1~W3)
- "예시로 보여 줘" → 지어낸 A사 사례로 시연

숫자를 적어도 되고 광고 관리자 캡처나 내보내기 파일을 올려도 된다. 비밀번호 · 토큰은 받지 않는다. 스킬이 광고를 직접 켜거나 끄지는 않는다. 할 일은 "하겠습니다 · 요청하겠습니다"로만 정리한다.

## 대시보드
**보기**: `dashboard/`의 HTML 파일을 브라우저로 연다. 외부 파일 · 인터넷 연결 없이 그 파일 하나로 열린다. 체크리스트를 채우면 그 브라우저에만 저장된다.
- 이력판: 줄 = 점검 자리, 칸 = 지난 날(데일리 13일 · 위클리 7주), 오른쪽 끝 = 이번 점검.
- 진행 순서 탭: 스킬의 카드 흐름과 이번 실행이 지난 자취를 보여 준다.

![예시 대시보드 v4.1 데일리 — 이력판](docs/screenshots/v4.1_데일리_1440_light_top.png)

**다시 만들기**(파이썬 3, 추가 설치 없음)
```sh
zsh tools/make_example.sh            # 예시 데이터로 dashboard/ v4.1 두 파일을 다시 만든다(작업 폴더 ./runs_example)
python3 tools/gen_checklist.py       # html/checks.js → references/checklist.md · engine/checklist.json
python3 html/build.py                # html/ → dashboard/ROAS_점검_지도.html
```
- 다시 만든 데일리 화면은 실행한 날짜에 따라 신호판 근거 한 문구('전환이 늦게 잡히는 중일 수 있다')가 빠질 수 있다. 엔진이 오늘 날짜와 비교하기 때문이다. 나머지는 같다.
- 실제 계정으로 돌리는 순서(광고 관리자 내보내기 · 메타 API · 웹 점검)는 `engine/README.md`에 있다. 메타 API는 읽기만 하고, 토큰은 환경변수로만 받는다.

## 시험 결과
2026-10-23에 시나리오 4개로 시험했다. 측정 끊김, 업종 전체 하락(시장), 서툰 사용자(캡처만 줌 · 기간 틀림 · 오타 · 품절)는 데일리, 소재 피로는 위클리다. 모델은 6개(Claude 오푸스 · 소넷, Codex 계열 3개, 제미나이)를 썼다. 시험 에이전트는 49회 띄웠고 실제로 돈 것은 47회다(제미나이 2회는 할당량이 떨어져 시작하지 못했다). **47회 중 원인을 틀린 경우는 0회**였다. 최종 6모델 24회 중 3회는 근거나 할 일이 덜 채워져 '부분'으로 채점됐다. 자세한 표와 실패 사례는 `docs/스킬시험_v2.md`에 있다.

## 남은 한계
- 시험은 에이전트 하나가 점검 쪽과 사용자 쪽을 함께 맡은 모의 대화였다. 실제 사람과의 시험은 아직 없다.
- 맨 마지막 판은 Claude 2개 모델로 3회만 확인했다. 다른 모델은 사용량이 다 떨어져 다시 돌리지 못했다.
- 웹 대화에서는 계산을 손으로 해서 평소 범위 같은 숫자를 잘못 계산한 적이 있다. 판정이 바뀐 경우는 없었다.
- 메타 광고 연결(MCP)로 숫자를 직접 읽는 갈래는 제안만 했고 넣지 않았다(`docs/스킬시험_v2/메타연결_제안.md`).
- 대시보드 진행 순서 탭의 문구는 `SKILL.md`를 손으로 줄여 넣은 것이라, 스킬을 고치면 화면 틀도 손으로 맞춰야 한다. 이력은 실행 폴더가 쌓여야 생긴다.
- 광고 관리자 메뉴 이름은 메타 화면 버전에 따라 조금 다를 수 있다.
